# Social API Research

Use official provider documentation first.

Required output: - endpoint - scope/permission - account type -
quota/rate limit - token behavior - supported metrics - publishing
limitations - audit/review requirements - last verified date

Update `docs/01-SOCIAL_API_CAPABILITIES.md`.

Never infer undocumented capabilities.
